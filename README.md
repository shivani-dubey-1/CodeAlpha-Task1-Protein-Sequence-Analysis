CodeAlpha Task 1 – Protein Sequence Analysis

📌 Overview

This project presents protein sequence analysis performed using NCBI BLASTP as part of the CodeAlpha Bioinformatics Internship – Task 1.

🎯 Objective

To analyze a protein sequence and identify similar protein sequences using BLASTP, based on sequence similarity, query coverage, and E-value.

🧬 Query Information

- Protein: Kinase
- Organism: Trypanosoma grayi
- Accession: XP_009311342.1
- Query length: 279 amino acids
- Molecule type: Amino acid
- Database: ClusteredNR
- Program: BLASTP

🔬 Analysis

The protein sequence was analyzed using NCBI BLASTP. The search results provided similar protein sequences along with important parameters such as:

- Percentage identity
- Query coverage
- E-value
- Alignment score
- Accession numbers

The BLAST results showed significant similarity between the query protein and several kinase-related protein sequences.

📊 Result

The analysis helped identify homologous protein sequences and provided information about their sequence similarity and statistical significance.

🧠 Learning Outcome

Through this task, I learned how to use NCBI BLASTP for protein sequence analysis and how to interpret BLAST results using parameters such as percentage identity, query coverage, and E-value.
